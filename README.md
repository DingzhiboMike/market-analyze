# market-analyze

Скилл для Claude.

Разведочный срез информационного поля под конкретную B2B-аудиторию: что её реально волнует, как реагирует рынок, кто уже закрывает её боли. Работает в четыре фазы с согласованием плана поиска. На выходе — аналитическая записка с цитатами аудитории и приоритизацией тем по осям «интенсивность × незакрытость».

## Когда использовать

- Подготовить вебинар или контент-план
- Собрать боли B2B-сегмента
- Понять, о чём пишет и спорит аудитория

Не подходит для одиночных фактов и документа-портрета ЦА (target-audience-analyst).

## Установка

**Claude Code.** Склонируйте репозиторий в папку скиллов:

```bash
git clone https://github.com/DingzhiboMike/market-analyze.git ~/.claude/skills/market-analyze
```

**Claude.ai / десктоп-приложение.** Скачайте репозиторий как ZIP (Code → Download ZIP) и загрузите его в настройках Claude, в разделе со скиллами.

После установки скилл включается сам, когда запрос подходит под его описание. Можно вызвать и явно — по имени `market-analyze`.
